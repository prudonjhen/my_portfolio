# Jennilyn Prudon Portfolio

A responsive and aesthetic personal portfolio website created to showcase a student's background, skills, projects, education, and contact information.

## Project Description
This portfolio was designed as a modern one-page website with a feminine and polished visual style. It includes sections for:

- Home / Introduction
- About Me
- Experience
- Skills
- Projects
- Education and Achievements
- Contact

The website is built to be easy to navigate, visually appealing, and mobile-friendly. It also includes interactive elements like a dark mode toggle, project filtering, animated statistic counters, scroll reveal effects, and a contact form with validation.

## What We Used
- HTML5 for page structure
- CSS3 for layout, colors, responsiveness, and aesthetic styling
- JavaScript for interactivity and user experience improvements
- Google Fonts for typography
- Responsive design for desktop, tablet, and mobile screens

## How We Built It
We created the website in a simple and clean structure:

1. Built the main page structure using semantic HTML sections.
2. Designed the layout with CSS variables, gradients, rounded cards, and soft pastel colors.
3. Added responsive media queries so the design adapts to smaller screens.
4. Added JavaScript to include:
   - mobile menu toggle
   - dark/light mode switch
   - project category filtering
   - animated counters for quick facts
   - reveal-on-scroll animations
   - contact form validation
5. Refined the visual design to make it more modern, readable, and aesthetically pleasing.

## File Structure
- `index.html` — main portfolio page
- `styles.css` — styling and responsive design
- `script.js` — interactive features

## How to Run
You can open the portfolio directly in a browser:

```bash
start index.html
```

Or run a local server from the project folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deployment
This portfolio can be deployed using GitHub Pages or Vercel because it is a static website built with HTML, CSS, and JavaScript.
